# גל־קול | מעבדת שמע מתקדמת
> **שומעים. רואים. מבינים.**

אפליקציית Android מקורית ומתקדמת לניתוח אקוסטי, עיבוד אותות ספרתי (DSP) בזמן אמת, מדידת עוצמות קול, הקלטה וניתוח קובצי שמע.

---

##  תכונות עיקריות

### 1. ניתוח חי בזמן אמת
- **מד עוצמה (VU-Meter):** תצוגת מחוון גראפי מעגלי ברור ומדויק של עוצמת הקול.
- **מדידות מדויקות:**
  - RMS (עוצמה ממוצעת בריבוע).
  - Peak Amplitude & Peak dBFS.
  - Crest Factor (מקדם שיא) לזיהוי דינמיקה ופולסיביות של הקול.
  - Leq (רמת חשיפה משוקללת לאורך זמן).
  - אינדיקטור יציבות אקוסטית (צליל יציב / תנודתי / פולסיבי).
- **הבחנה מדעית קפדנית בין dBFS ל־dB SPL:**
  - ערכי ברירת המחדל מוצגים ב־dBFS (עוצמה דיגיטלית יחסית לתקרה הדיגיטלית).
  - תמיכה בכיול מיקרופון ייעודי לאמידת dB SPL פיזיקלי.
  - נקודת ייחוס לדיבור רגיל (60 dB SPL) והשוואה ברורה בלשון פשוטה.

### 2. תצוגת Waveform מקצועית
- גל קול רציף המבוסס על דגימות PCM 16-bit אמיתיות מתוך זרם המיקרופון.
- שינוי צבע דינמי של הגל בהתאם לעוצמה (טורקיז -> ענבר -> אדום בעת קטימה).
- שליטה בחלון הזמן (Zoom) בין 10ms ל־500ms.
- הקפאת הגרף (Freeze) לבחינת צורת הגל, ומצב מסך מלא.
- לחיצה על הגרף (Tap to inspect) לקריאת ערך מדויק של זמן ומשרעת.

### 3. ניתוח תדרים מתקדם (FFT & Spectrogram)
- אלגוריתם **Cooley-Tukey Radix-2 FFT** אמיתי ומדויק.
- פונקציות חלון מתמטיות לבחירה: **Hann**, **Hamming**, **Blackman**, ו־**Rectangular**.
- אינטרפולציה פרבולית למציאת התדר הדומיננטי בדיוק תת-ביני (Sub-bin accuracy).
- חישוב מרכז כובד ספקטרלי (Spectral Centroid) לאפיון בהירות הגוון.
- ספקטרוגרמה דו-ממדית (Waterfall Heatmap) המציגה את התפתחות התדרים לאורך ציר הזמן.
- התפלגות אנרגיה ל־7 תחומי תדרים אקוסטיים (סאב-באס, באס, מיד נמוך, מיד, מיד גבוה, טרבל, אוויר).

### 4. הקלטה וניהול שמע
- הקלטת שמע מקומית ישירה בפורמט **WAV PCM 16-bit** תקני (44.1 kHz).
- שיתוף אותו זרם שמע בין הניתוח החי למקליט ללא פתיחת מופעים מתחרים של המיקרופון.
- תצוגת גל קול וזמן חולף במהלך ההקלטה.
- נגן פנימי מובנה, שינוי שמות, מחיקה, שיתוף קובצי WAV, ומעבר ישיר לניתוח מעבדתי.

### 5. ניתוח קובצי שמע מהמכשיר
- בורר קבצים של מערכת ההפעלה (ללא צורך בהרשאות אחסון מיותרות).
- תמיכה ב־WAV, MP3, M4A, AAC, OGG.
- פענוח באמצעות Android `MediaCodec` ו־`MediaExtractor` לדגימות PCM.
- זיהוי מקטעים שקטים, מקטעים חזקים וזיהוי קטימה דיגיטלית (Digital Clipping).
- בחירת מקטע ממוקד (Range Selector) לניתוח ספקטרום וגל נקודתי.

### 6. השוואת מדידות והפקת דוחות
- השוואה מקבילה בין 2 מדידות: הפרשי RMS, הפרשי שיא, שוני בדינמיקה, ותרגום מילולי בעברית.
- הפקת דוח **PDF מקצועי בעברית** בעימוד מלא, הכולל טבלאות נתונים והערות שוליים.
- ייצוא היסטוריה בפורמט **CSV** ו־**JSON**.

## 🛠 ארכיטקטורה וטכנולוגיות

- **שפה:** Kotlin בלבד.
- **ממשק:** Jetpack Compose, Material 3, תמיכה מלאה בכיווניות ימין-שמאל (RTL).
- **גופנים:** שימוש בגופן העברי **Rubik** לטקסטים ובגופן **Roboto Mono** למספרים ותדרים.
- **בסיס נתונים:** Android Room Database לשמירת מדידות והקלטות מקומית.
- **עיבוד רקע:** Kotlin Coroutines (`Dispatchers.IO`) לעיבוד שמע ללא חסימת ממשק המשתמש.
- **פרטיות ועבודה במצב לא מקוון:** 100% מקומי, ללא שרתים, ללא שימוש ברשת, ללא שירותי AI חיצוניים.

## 🚀 בנייה באמצעות GitHub Actions

הפרויקט כולל קובץ הגדרות מוכן לבנייה ידנית ב־GitHub:
`.github/workflows/build.yml`

### כיצד להפעיל בנייה וליצור מהדורה (Release):
1. היכנס למאגר ב־**GitHub**.
2. עבור ללשונית **Actions**.
3. בחר בצד שמאל ב־**Build Android APK & Release**.
4. לחץ על **Run workflow**.
5. המערכת תבצע:
   - בדיקת קוד והרצת בדיקות יחידה (`testDebugUnitTest`).
   - קומפילציה ובניית APK.
   - יצירת **GitHub Release** חדש תחת תגית גרסה אוטומטית (למשל `v1.0.1`).
   - העלאת קובץ ה־APK להורדה ישירה מתוך המהדורה וכ־Artifact.
